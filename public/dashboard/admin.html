How new accounts work

  1. Choose Create User, pick Student or Teacher and enter the full name. The next free ID is assigned for you.
  2. A temporary password is shown once. Copy it and hand it to the person, in person or on paper.
  3. When they first sign in they are asked to choose their own password. After that, nobody else knows it.
  4. Forgot a password? Use Reset password in the Users list to issue a new temporary one.

Good to know

  • The temporary password is shown only once. It is not stored anywhere in readable form.
  • The person must replace it the first time they sign in.
  • IDs are never reused, even if an account is disabled.
  • Extra admin accounts are not created here, for safety.
